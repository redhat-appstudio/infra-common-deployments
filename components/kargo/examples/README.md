# Kargo examples

This directory is documentation and scaffolding only. It is not included by the
staging or production Kustomizations.

[project](project/) contains the historical project scaffold moved out of the
production project list. Its nested examples predate the shared promotion workflow;
do not copy their inline workflow or soak policy into a new component.

Use the [current onboarding guide](../internal-production/docs/onboarding.md)
and its maintained component references for new work. Rewriting or removing the
historical examples is separate from the production layout migration.
